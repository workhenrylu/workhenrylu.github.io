# 个人工资数据大屏

深色科技风个人工资可视化大屏，单文件 HTML，离线可用，数据不出本机。

## 功能特性

- **9 大图表 + 8 项 KPI 指标卡 + 月度明细表**：收入趋势、收入构成、扣款构成、社保公积金与年金、个税趋势、年度对比、补贴福利构成
- **时间范围筛选**：年份快捷按钮（全部 / 本年 / 近3年 / 近5年 / 具体年份）+ 起止月微调
- **数据更新**：右上角「导入数据」按钮，支持上传腾讯文档导出的 CSV / XLSX 文件，自动解析、本地持久化
- **数据安全**：纯本地运行，无任何网络请求，数据不离开本机
- **完美适配**：任何分辨率窗口自适应铺满，无黑边

## 数据口径

- 应发工资 = 基本工资 + 月度效益 + 预发效益奖 + 各类补贴 + 综合福利（不含企业年金）
- 实发金额 = 应发 − 养老 − 医疗 − 失业 − 公积金 − 企业年金 − 个税
- 广义工资 = 实发金额 + 公积金 × 3 + 企业年金 × 5

## 使用方法

1. 双击 `index.html` 即可在浏览器中打开使用
2. 数据更新：腾讯文档 → 导出 CSV/XLSX → 大屏右上角「导入数据」上传

## 上传 CSV 格式要求

列头需包含（字段名与腾讯文档智能表格一致）：

```
基本工资,月度效益,预发效益奖,野外补贴,生活补贴,通讯补贴,车改补贴,住房补贴,
防暑降温,综合福利,企业年金,养老保险,医疗保险,失业保险,住房公积金,个人所得税,工资所属期
```

`工资所属期` 支持 `YYYY-MM-DD` 或毫秒时间戳。支持 UTF-8 / GBK 编码。
